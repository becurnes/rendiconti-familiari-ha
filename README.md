# Rendiconti familiari per Home Assistant OS

App locale per registrare spese anticipate per familiari, ripartire le quote e tenere traccia dei versamenti per mese. Include l'importazione di uscite da CSV o da una tabella e la stampa su rotoli termici da 58 o 80 mm.

## Installazione

1. Apri **Impostazioni → App → Installa app** in Home Assistant.
2. Nel menu **⋮ → Repository**, aggiungi l'indirizzo di questo repository GitHub.
3. Apri **Rendiconti familiari**, seleziona **Installa**, poi **Avvia**.
4. Attiva **Mostra nella barra laterale** e apri **Rendiconti**.

Quando compare una nuova versione, usa **Aggiorna** dalla schermata dell'app. Il database dei rendiconti è salvato in `/data` sul dispositivo che esegue Home Assistant. Puoi includerlo nei backup di Home Assistant selezionando l'app.
